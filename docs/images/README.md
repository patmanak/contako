# README illustrations

The README uses the application's transparent octopus mascot directly, without
duplicating its runtime source. Its origin is documented in the
[artwork record](../../app/design/brand/README.md).

`login.png`, `contacts.png` and `contact.png` show Contako's real Android Compose
screens in English and the light theme, rendered on a physical device with isolated fictional
data. No real account, credentials, contact data or system notifications are
included. The sign-in form is empty. The directory and detail illustrate the
interface, not the outcome of a live synchronization test.

Contact names, organizations, addresses and notes are fictional. Email and web
addresses use the reserved `example.org` domain; the phone number is from the
fictional North American 555-0100–0199 range. Amelia Reed's card illustrates
a richer contact with structured names, organization, title, email, phone,
postal address, website and note. No stock portrait or third-party photograph
is used.

The captures contain project UI and artwork; retain the project's license,
artwork attribution and independent-Proton-project notice when reusing them.
Update screenshots when the represented interface materially changes, and inspect
every exported image for personal data before publication.
